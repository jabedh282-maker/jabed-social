# Mehedi H Jabed: Portfolio

Personal portfolio and link page, live at **https://jabed-social.vercel.app**

| File | What it is |
|---|---|
| `index.html` | Portfolio in English, বাংলা and العربية, Sky theme with a dark-theme switch |
| `links.html` | Link-in-bio page, served at `/links` |
| `404.html` | Not-found page |
| `me.jpg` | Profile photo |
| `work/` | Project images for the Work section (`*-t.jpg` are thumbnails) |
| `work/enma/` | Enma Security posts and Reels (videos compressed to 720p for the web) |
| `Mehedi-H-Jabed-CV.pdf` | One-page CV, linked from the Download CV buttons |
| `og.jpg` | 1200×630 preview image for WhatsApp, Facebook and X |
| `favicon.svg`, `apple-touch-icon.png` | Site icons |
| `vercel.json` | Clean URLs, security and cache headers |
| `robots.txt`, `sitemap.xml` | Search engine files |

Plain HTML, no build step. Vercel deploys every push to `main`.
Language and theme choices are saved in the browser.
Concept projects in the Work section are self-initiated samples for fictional brands and are labelled as such on the site.
Icons are inline SVG from Font Awesome Free 6.5.1 (CC BY 4.0).
